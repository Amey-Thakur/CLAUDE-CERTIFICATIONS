# Course completion certificates

Certificates earned by the maintainer, Amey Thakur, for completing the Anthropic Academy courses that back this certification program. They are included as a record of having worked through the curriculum this repository documents. Course completion certificates are distinct from the certification credentials themselves, which are issued as Credly badges after a proctored exam.

Each certificate is stored as the issued PDF, with a PNG preview in [previews](previews/). Where the certificate carries an issue date and a Skilljar verification link, both are listed; the remaining certificates are issued without a printed date.
